Phase 1 (March 14):
    Purpose : Benchmark dataset, LLM and Retrieval source locking
    1) Benchmark dataset : Truthful QA
    2) LLMs : WatsonX AI (Mistral AI + GPT)
    3) Retrieval source : Wikipedia
    4) Pipeline : 
        Take question from Truthful QA -> Ask GPT and Mistral to generate answer -> Extract factual claims -> Retrieve wikipedia evidence -> Compare claim vs evidence -> Flag hallucinated claims -> Rewrite hallucinated claims -> Score original vs rewritten answer

    5) Hallucination detection logic : 
        5.1) Evidence relevance : How relevant is wikipedia retrieved chunk to the model generated answer
        5.2) Support / Contradiction score 
    
    6) Claim extraction module : 
        6.1) Split LLM output into sentences
        6.2) Apply Claim worthiness filter
        6.3) Keep only factual sentences for Retrieval testing
    
    7) Retrieval module : 
        7.1) Query wikipedia 
        7.2) Chunk page into sections
        7.3) Rank them by similarity 
        7.4) Keep top k relevant passages
    
    8) Correction Module : 
        8.1) Ask LLM to rewrite answer from the corrected data retrieved from wikipedia
    
    Decision Engine : 
        IF relevance < threshold_r
            → label = INSUFFICIENT

        ELSE:
            IF contradiction_score > threshold_c
                → label = CONTRADICTED

            ELSE IF support_score > threshold_s
                → label = SUPPORTED

            ELSE
                → label = INSUFFICIENT
